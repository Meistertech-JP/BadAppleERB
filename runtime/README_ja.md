# Bad Apple!! ERB — メニュー統合版

Bad Apple!! の影絵映像を、**79桁×24行・256階調**の文字画面として計算し、最後まで表示するプログラムです。起動時のメニューから、経過時間に合わせる「時間同期」と、全6,573コマを表示する「全フレーム」を選べます。両方式の処理は、同じ `ERB/PLAYER.ERB` に収録されています。

通常起動には同梱の **PyPy 8.0.1（Python 3.12.15）と PyEmuera 3.0.0** を使用します。対応する同梱版では、Python の別途インストールは不要です。

English: [README_en.md](README_en.md)  
仕組みの詳しい説明: [HOW_IT_WORKS_ja.txt](HOW_IT_WORKS_ja.txt)

## 起動方法

配布アーカイブをフォルダーごと展開してください。`ERB`、`CSV`、数値データ、実行ファイルの配置を保ったまま起動します。診断ログと再生記録を保存するため、展開先には書き込み権限が必要です。

### Windows x64

展開したフォルダーの **`BadAppleERB.cmd`** を起動します。

起動スクリプトは、同じフォルダーの `console_utf8.py` を使って、コンソールの入出力と Python の文字出力を自動的に UTF-8 へそろえます。終了時には、コンソールの入力・出力コードページをそれぞれ元の設定へ戻します。

### Linux x86_64

展開したフォルダーを端末で開き、次を実行します。

```sh
sh ./run.sh
```

端末は **80桁×25行以上**にし、日本語を表示できる等幅フォントを使用してください。UTF-8 のテキスト、24ビットカラー、ANSI の画面制御に対応する端末が必要です。

## メニューの操作

大きなリボン、リンゴ、魔女帽子と箒を描いた AA とともに、再生方式のメニューが表示されます。半角数字を入力し、Enter で決定します。

| 入力 | 動作 | 処理が間に合わない場合 |
|---|---|---|
| `1` | 時間同期で再生 | 遅れたコマを省略して、現在時刻に対応するコマへ進む |
| `2` | 全フレームを順番に再生 | コマを省略せず、再生時間が長くなる |
| `0` | 終了 | — |

再生が終わると、自動的にメニューへ戻ります。同じ方式で繰り返すことも、別の方式へ切り替えることもできます。空入力や対象外の番号を入力した場合は、メニューで再入力できます。再生中にプログラムを終了するには Ctrl+C を押します。

選択後に「読み込み中...」と表示されます。最初のデータ読み込みは映像の再生時間に含まれません。読み込んだデータは、同じ実行中の次の再生でも使用します。

### 1：時間同期

30 fps の時間軸を基準に、経過時間から表示対象のフレーム番号を決めます。目標の映像時間は **219.100秒（3分39.1秒）**です。計算や端末への表示が遅れた場合、次の選択時点の時刻に対応するフレームへ進みます。

最終フレームは必ず計算して表示します。早く到達した場合は映像の終端時刻まで保持します。終端直前の計算・表示がその時刻をまたいだ場合は、必要な処理の分だけ超過することがあります。

### 2：全フレーム

フレーム0から6,572まで、**6,573フレームすべて**を順に計算して表示します。30 fps の予定時刻より早い場合は待機し、遅れた場合も次のフレームを省略しません。処理性能によっては、全編の再生に219.1秒より長い時間がかかります。

## CPython を使用する

CPython 3.10以上を用意すると、同じプログラムとメニューを CPython でも実行できます。

Windows では、`python` コマンドで CPython が起動する状態にしてから **`BadAppleERB_CPython.cmd`** を使用します。

Linux では、次を実行します。

```sh
PYEMUERA_PYTHON=python3 sh ./run.sh
```

環境変数 `PYEMUERA_PYTHON` に実行ファイル名またはパスを設定すると、その指定を優先します。値には実行ファイルだけを指定し、追加のコマンドライン引数は含めません。起動スクリプトの選択順は、明示した実行ファイル、同梱 PyPy、システムの `python` または `python3` です。

## 表示と動作環境

本編は79桁×24行を使用します。再生中に操作説明や進行状況の行は表示しません。画面の右端と最下行に余裕を残すため、端末全体は80桁×25行以上にしてください。

明るい部分には半角の `#` を使い、文字色の R・G・B を同じ値にして256階調を表します。黒い部分は黒背景の空白です。映像のみを表示し、音声は再生しません。通常の再生には元の MP4、FFmpeg、NumPy は不要です。

一致の基準は、元動画を所定の条件で79×24セルへ縮小した参照映像です。元動画の512×384画素の細部は縮小されます。また、端末上の見た目には `#` の字形、行間、文字セルの縦横比が影響します。元映像の4:3に近い表示比率にするには、文字セルの高さを幅の約2.47倍にするのが目安です。

同梱処理系の主な条件は次のとおりです。

- Windows x64版: 64ビット Windows、Windows UCRT、Microsoft x64 Visual C++ ランタイム。
- Linux x86_64版: x86_64、glibc 2.28以上。
- PyPy 8.0.1 の Python 3.12 実装は、上流で beta と位置づけられています。

PyEmuera の配布バイナリーはそのまま使用しています。ライセンスと第三者への告知は、`LICENSE`、`pypy`、`third_party` に収録されています。

## 主なファイル

| ファイル・フォルダー | 内容 |
|---|---|
| `BadAppleERB.cmd` / `run.sh` | メニューを起動するスクリプト |
| `BadAppleERB_CPython.cmd` | Windows で CPython を選ぶ起動スクリプト |
| `console_utf8.py` | Windows のコンソールを UTF-8 に設定してエンジンを起動し、終了時に元のコードページへ戻す補助ファイル |
| `PyEmuera.pyz` | ERB を実行する PyEmuera |
| `pypy` | 対応する配布版に同梱された PyPy |
| `ERB/PLAYER.ERB` | メニュー、AA、フレーム計算、2種類の再生処理 |
| `ERB/PLAYER.ERH` | 再生中に使用する変数や状態の定義 |
| `ERB/GEOMETRY.ERH` | 座標・明度を計算する共有係数 |
| `txt00.txt`～`txt04.txt` | 曲線区間、出現・消失などの数値データ |
| `CSV` | ゲーム情報 |
| `packed_format.json` | 数値データの形式、件数、ファイルのハッシュ |
| `HOW_IT_WORKS_ja.txt` / `HOW_IT_WORKS_en.txt` | 生成方法と再生方式の詳細 |

`txt00.txt`～`txt04.txt` には、数値を Unicode 文字として格納しています。画面へそのまま出す文字絵ではありません。テキストエディターでの保存によって文字や改行が変わると読み込めなくなるため、配布時のファイルをそのまま使用してください。

## 困ったとき

**行が折り返される、画面が流れる**  
端末の文字数を80桁×25行以上にし、等幅フォントを使ってください。文字を大きくすると、同じウィンドウサイズでも収まる桁数・行数が少なくなります。

**濃淡や画面の更新が正しく見えない**  
24ビットカラーと ANSI の画面制御に対応する端末で起動してください。IDE の単純な出力欄や、制御文字を処理しないログ表示欄は再生用画面には適しません。

**メニューの日本語が四角や文字化けになる**  
Windows では、同じ配布版の `BadAppleERB.cmd` と `console_utf8.py` を両方展開し、`BadAppleERB.cmd` から起動してください。起動時に UTF-8 が自動設定されます。文字が四角になる場合は、日本語の字形を持つ等幅フォントや代替フォントを選びます。Linux では UTF-8 の端末を使用してください。入力に使う番号は半角の `1`、`2`、`0` です。

**時間同期で動きが飛ぶ**  
時間軸に追いつくためにフレームを省略しています。同梱 PyPy で起動しているかを確認できます。すべてのコマを表示したい場合は、メニューの `2` を選んでください。

**全フレームの再生が長い**  
全6,573コマを処理する方式の動作です。映像の時間軸に合わせたい場合は、メニューの `1` を選んでください。

**データを読み込めない**  
アーカイブ全体を展開し、`ERB`、`CSV`、`txt00.txt`～`txt04.txt`、`PyEmuera.pyz` の配置を確認してください。数値ファイルと `ERB/GEOMETRY.ERH` は、同じ配布物の組み合わせを使用します。起動スクリプトは自分のあるフォルダーを作業ディレクトリーにします。

**Windows で `VCRUNTIME140.dll` がないと表示される**  
Microsoft の x64 Visual C++ ランタイムをインストールしてください。32ビット版では同梱の64ビット PyPy の依存関係を満たしません。

**起動直後に終了する**  
`logs/diagnostics.log` を確認してください。起動スクリプトは標準エラーをこのファイルへ記録します。再生終了時の集計は `.pyemuera/logs` に保存されます。`PYEMUERA_PYTHON` を設定している場合は、その実行ファイルのパスとバージョンも確認してください。
